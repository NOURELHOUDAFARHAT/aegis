How this bulletin is made

From public feed to this page, every morning

  1. Collect. Four feeds are downloaded and published to Kafka (Redpanda), each record checked against an Avro schema.
  2. Land. A writer appends them to Apache Iceberg tables in S3-compatible storage, the Bronze layer: raw and never edited.
  3. Model. dbt builds deduplicated Silver tables and question-shaped Gold tables in DuckDB, with data tests that stop the build on a broken rule.
  4. Learn. scikit-learn clusters malware servers into campaigns and ranks new vulnerabilities, each model evaluated the way it is used.
  5. Publish. An allow-listed export writes these files. Honeypot addresses leave only as keyed pseudonyms.
